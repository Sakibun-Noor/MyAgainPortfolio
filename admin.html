Almost there.

This dashboard needs your Supabase project before it can do anything.

  1. Create a free project at supabase.com.
  2. Open SQL Editor, paste in the contents of schema.sql, and run it.
  3. Go to Authentication → Users → Add user and create your own admin login.
  4. Go to Authentication → Sign In / Providers and turn off new sign-ups.
  5. Copy Project URL and the anon public key from Project Settings → API into config.js.
